GinN — оптимизатор игр в духе HONE, который работает и на ПК, и на телефоне. Он показывает, на что способно
твоё железо, одной кнопкой включает полезные настройки системы, следит за нагрузкой и температурой
и подбирает под каждую игру реальный потолок FPS и «картофельные» настройки графики для слабых устройств.
GinN ничего не обещает впустую: если система что-то не разрешает, приложение так и пишет и открывает нужный
экран настроек. Любое изменение можно откатить.

## Возможности

Общее для обеих платформ:

- **Главная** — модель, процессор, видеокарта, ОЗУ, память, экран и батарея, класс устройства и оценка.
- **Мониторинг** — нагрузка и частота процессора, ОЗУ, температура и тепловой режим в реальном времени.
  Если система какое-то значение скрывает (на Android, например, загрузку процессора), GinN не подставляет
  выдуманные числа.
- **Игры** — находит установленные игры. Для каждой считает максимальный FPS (по экрану, классу железа
  и лимиту самой игры) и выдаёт рецепт настроек «Картошка» или «Баланс».
- **Оптимизация** — список твиков с описанием, что каждый делает, и кнопка «Оптимизировать всё».

### Телефон (Android)

Android не даёт обычным приложениям менять системные настройки и настройки других игр. Поэтому GinN
честно делит всё на две части.

**Делает сам**

- **Ускорение** — закрывает фоновые приложения и показывает, сколько ОЗУ освободилось. Работает
  на Android 10–13; на Android 14+ система это запрещает, и GinN так и пишет.
- **«Не беспокоить»** на время игры — после твоего разрешения.
- **Запуск игры с ускорением** — закрывает фон и включает «Не беспокоить».
- **Серые текстуры для Minecraft Bedrock** — пакет `.mcpack` сохраняется в «Загрузки».

**Проверяет и подсказывает** — смотрит реальное состояние и открывает нужный экран настроек:

- экономия заряда;
- частота экрана — текущая и максимальная;
- скорость анимаций в «Для разработчиков»;
- свободная память.

Для графики в самих играх GinN даёт пошаговый рецепт: что выставить в меню игры под выбранный FPS.

### ПК (Windows)

На Windows GinN меняет настройки сам и перед каждым изменением сохраняет старое значение.

- **Твики системы:** схема питания «Максимальная производительность», игровой режим, фоновая запись
  Game Bar, планирование GPU, приоритет игр, визуальные эффекты, ускорение мыши, сетевые задержки и другие.
  Полный список — во вкладке «Оптимизация», у каждого пункта написано, что он делает.
- **Действия:** очистка временных файлов, сброс кэша DNS, точка восстановления Windows.
- **Профили игр:** для поддерживаемых игр (Minecraft Java, Counter-Strike 2, Fortnite) GinN сам записывает
  файлы настроек — лимит FPS и «картошку»; для Minecraft ещё и пакет серых текстур. Для остальных игр —
  рецепт настроек.
- **Подсказки:** автозагрузка и выбор видеокарты в «Настройках графики» Windows открываются кнопкой —
  решаешь ты.
- Часть твиков требует прав администратора — GinN предложит перезапуститься от имени администратора.

### GinN AI — ИИ-оптимизатор (Claude)

Вкладка **«ИИ»** работает и на телефоне, и на ПК. Выбираешь цель — максимум FPS, минимальная задержка,
меньше нагрев и расход батареи или стабильный FPS, — по желанию игру и нужный FPS. ИИ смотрит на железо,
текущее состояние настроек и установленные игры и собирает личный план: что включить, зачем, какой лимит FPS
поставить и что выставить в самой игре.

- Перед применением видно каждый пункт с объяснением — лишнее можно снять галочкой. Потом одна кнопка
  **«Применить план»**. Всё, что применено, откатывается кнопкой «Откатить».
- ИИ может выбрать только твики, которые уже есть в GinN: он не отключает антивирус, обновления или
  брандмауэр и не разгоняет железо.
- После плана можно задавать вопросы в чате («почему лагает в CS2?»).
- Работает на **Claude от Anthropic** через официальный SDK. Нужен **свой API-ключ** с
  [platform.claude.com](https://platform.claude.com/) — запросы оплачиваются с этого ключа. Модель
  выбирается в настройках:

  | Модель | Когда | Примерная цена одного анализа |
  |---|---|---|
  | Claude Opus 5.5 (по умолчанию) | лучшее качество | ≈ $0.07 |
  | Claude Sonnet 5.5 | быстрее и дешевле | ≈ $0.03 |
  | Claude Haiku 5.5 | самый дешёвый | ≈ $0.002 |

  Точная стоимость каждого анализа показывается под планом.
- **Что уходит в Claude:** характеристики железа, состояние настроек GinN, список игр и твоя цель.
  Имя устройства, имя компьютера и личные данные не отправляются.
- **Где хранится ключ:** только на устройстве — на ПК зашифрован средствами Windows, на Android лежит
  в закрытых настройках приложения. Наружу он уходит только в запросах к Claude.
- **Без ключа** есть «Базовый анализ без ИИ» — план по встроенным правилам. Он так и подписан и не
  выдаётся за ИИ.

## Установка

### Android

1. Скачай `GinN.apk` и открой его из уведомления или папки «Загрузки».
2. Если телефон пишет, что установка из неизвестных источников запрещена, нажми «Настройки» и включи
   «Разрешить установку из этого источника» для браузера или файлового менеджера.
3. Нажми «Установить». Если Play Защита предупредит о неизвестном приложении — это потому, что GinN нет
   в Google Play: раскрой «Подробнее» и установи всё равно.

Если обновление не ставится поверх старой версии («Приложение не установлено»), удали GinN и установи
заново: пока у проекта нет постоянного ключа подписи, ключ может отличаться от сборки к сборке. Владелец
репозитория может это исправить — см. «Подпись APK» в разделе «Разработка».

### Windows

1. Скачай `GinN-Setup-….exe` (установщик) или `GinN-Portable-….exe` (запускается без установки).
2. Программа пока без цифровой подписи, поэтому SmartScreen может показать окно «Windows защитила ваш
   компьютер». Нажми **«Подробнее» → «Выполнить в любом случае»**.
3. Для части твиков нужны права администратора — GinN предложит перезапуститься от имени администратора.

### Через Termux

```sh
pkg install -y git
termux-setup-storage            # разреши доступ к памяти
git clone --depth 1 https://github.com/gghub433/opmizer
cp opmizer/release/GinN.apk ~/storage/downloads/
```

Потом открой `GinN.apk` в «Загрузках». Обновить позже:

```sh
cd ~/opmizer && git pull && cp release/GinN.apk ~/storage/downloads/
```

Или одной командой без git:

```sh
curl -L -o ~/storage/downloads/GinN.apk https://raw.githubusercontent.com/gghub433/opmizer/main/release/GinN.apk
```

## Безопасность

- Перед каждым изменением GinN запоминает старое значение. Кнопка **«Откатить»** возвращает всё, что
  поменял GinN: твики системы и файлы настроек игр.
- На ПК перед первой оптимизацией создай **точку восстановления** — это действие есть во вкладке
  «Оптимизация». Если что-то пойдёт не так, Windows откатится к ней.
- «Оптимизировать всё» включает только рекомендованные твики. Системные настройки сами не открываются,
  а твики с перезагрузкой честно об этом предупреждают.
- На Android у GinN нет прав менять систему: он только закрывает фоновые приложения, включает
  «Не беспокоить» и открывает нужные экраны настроек.

## Структура проекта

```
ui/                            общий интерфейс: HTML + CSS + JS без сборки и без интернета
  assets/logo.svg              логотип
  css/ginn.css                 дизайн-система и стили страниц
  js/                          ядро, адаптер хоста, мок, каталог игр, компоненты, страницы
  js/ai/advisor.js             GinN AI: сбор данных, запрос к Claude, проверка и применение плана
  js/vendor/anthropic-sdk.js   официальный SDK Anthropic для браузера (собирает tools/build-sdk-bundle.sh)
android/                       приложение для Android: WebView + мост на Java (без androidx)
desktop/                       приложение для Windows на Electron
  src/                         твики, реестр, железо, игры, профили игр
  test/                        юнит-тесты (node:test)
  build/                       иконки приложения
release/GinN.apk               готовый APK для прямой ссылки
docs/ARCHITECTURE.md           контракт: API хоста, форматы данных, дизайн-токены
.github/workflows/build.yml    сборка APK и exe, релиз ginn-latest
```

Интерфейс один на все платформы: на телефоне его показывает WebView из ресурсов APK, на ПК — окно
Electron. Связь с системой идёт через `GinN.host` (описан в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)).

## Разработка

### Интерфейс в браузере

Интерфейс работает без сборки, с фейковым хостом (`ui/js/mock.js`):

```sh
cd ui
python3 -m http.server 8000
```

- `http://localhost:8000/` — как на Android
- `http://localhost:8000/?platform=windows` — как на Windows
- `?aidemo=1` — демо ИИ без ключа и без запросов к Claude

### ПК (Electron)

Нужен Node.js 22.

```sh
cd desktop
npm ci
npm start        # запустить приложение
npm test         # юнит-тесты
npm run dist     # собрать GinN-Setup и GinN-Portable в desktop/dist (лучше на Windows)
```

Electron показывает `desktop/renderer/` — это копия `ui/`, её обновляет `npm run sync-ui`.

### Android

Нужны JDK 17, Gradle 8.7+ и Android SDK (`ANDROID_HOME` или `android/local.properties` с `sdk.dir`).

```sh
gradle -p android assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

Публикуется release-сборка: в ней выключена отладка, поэтому сохранённый ключ ИИ нельзя достать через
`adb`/DevTools.

**Подпись APK.** Без своего ключа CI подписывает APK отладочным ключом сборщика, и он меняется от сборки
к сборке. Чтобы обновления ставились поверх, создай ключ один раз
(`keytool -genkeypair -v -keystore ginn.jks -keyalg RSA -keysize 4096 -validity 10000 -alias ginn`) и добавь
в Settings → Secrets → Actions секреты `GINN_KEYSTORE_B64` (`base64 -w0 ginn.jks`), `GINN_KEYSTORE_PASSWORD`,
`GINN_KEY_ALIAS` и `GINN_KEY_PASSWORD`.

Папка `ui/` подключается к APK напрямую как assets — копировать ничего не нужно.

### CI

Каждый push, который меняет `android/`, `ui/` или `desktop/`, запускает
[Build GinN](.github/workflows/build.yml): APK собирается на Ubuntu, exe — на Windows (сначала проходят
тесты), а затем обновляется релиз [`ginn-latest`](https://github.com/gghub433/opmizer/releases/tag/ginn-latest).
Сборку можно запустить и вручную во вкладке Actions.
